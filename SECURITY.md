# Segurança

## Como avisar sobre uma falha

Achou um jeito de assumir o perfil de um negócio sem aprovação, entrar na conta de outra pessoa ou ver dados que não deveria? **Não abra uma issue pública.**

Use o aviso privado do GitHub: na aba **Security** do repositório, clique em [**Report a vulnerability**](https://github.com/fabs-reis/Negocio-do-bem/security/advisories/new). Só quem mantém o projeto vê o que você enviar.

Conte:

- o que você encontrou e onde (página, rota ou arquivo);
- como reproduzir, passo a passo;
- o que alguém conseguiria fazer com isso.

A conversa segue por lá mesmo. Quando a correção for publicada, você recebe o crédito, se quiser.

## O que entra

Só a versão atual da branch `main` recebe correções.

As contas do seed (senha `senha-demo-123`) não contam como falha: o seed é só para desenvolvimento e se recusa a rodar em produção.
